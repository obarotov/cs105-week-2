## Compiling and Running

Each folder contains a standalone C program. Compile and run it with:

```bash
gcc -o <program_name> <file_name>.c
./<program_name>
```

Replace `<file_name>` with the problem's source file (e.g. `scrabble.c`) and `<program_name>` with whatever you'd like the compiled output to be called.

Note that `caesar` and `substitution` take a command-line key, e.g. `./caesar 13` or `./substitution YTNSHKVEFXRBAUQZCLWDMIPGJO`.
